# @desk/contracts

跨端契约的 **TypeScript 生成层** — 与根 `contracts/` schema 对齐的唯一真相源。

## 边界

- **属于**：由 `sync_contracts.py` 生成的 TS 类型（IPC 请求/响应、实体、事件）。
- **不属于**：手工编写的类型；IPC 封装（`@desk/platform/ipc`）；业务状态（`@desk/store`）。

## Usage

由 `pnpm contracts:sync`（或 `tauri dev/build` 前自动）生成，写入手写的 `src/generated/*`。

## Directory

- `src/generated/` — 自动生成类型（文件头 `// Auto-generated by sync_contracts.py`）
- `src/index.ts` — 唯一导出 `export * from "./generated"`

## 禁止

- 手改 `src/generated/*`（改动需走 `contracts/` schema + codegen）。
- 在本包内引入运行时依赖（纯类型包）。
